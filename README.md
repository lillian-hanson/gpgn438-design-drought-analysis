# Geophysics Capstone Design Project
### Lillian Hanson, Aucklynn Sacco
### Advisor: Ryan Venturelli
---
We propose to create a historical evaluation of Colorado groundwater, precipitation, and aquifer volume patterns and their effects on local agriculture. We will also examine how El Ni\~no--Southern Oscillation 
(ENSO) cycles influence water supply availability. Using this analysis, we will develop a forward-looking model and provide local agriculturists with a multi-stage plan for anticipated water usage.
